Features

Everything You Need for Smart Composting

Our IoT-powered system monitors every aspect of the composting process to ensure optimal conditions.

Temperature Monitoring

DHT22 sensor tracks compost temperature in real-time. Optimal range: 30–40 °C for aerobic decomposition.

Target: 30–40 °C

Moisture Sensing

Capacitive soil moisture sensor measures compost moisture content. Target range: 50–65 % for ideal composting.

Target: 50–65 %

Automatic Aeration

12V DC fan with mesh filter, controlled via MOSFET relay. Auto-activates when temperature exceeds 30 °C threshold.

Auto Mode

Process

How It Works

From food waste to nutrient-rich compost — automated and monitored every step of the way.

01

Sensors Read Data

DHT22 measures temperature & humidity. Capacitive soil sensor measures moisture content every 2 seconds.

02

ESP32 Processes

Microcontroller reads sensor data, determines if aeration is needed, and controls the relay-driven fan.

03

Data Sent to Cloud

Sensor readings are pushed to Firebase Realtime Database via Wi-Fi for cloud storage and remote access.

04

Live Dashboard

This website pulls real-time data from Firebase and displays interactive charts, gauges, and alerts.

05

Auto Aeration

When temperature exceeds 30 °C, the fan turns on automatically to maintain optimal composting conditions.

Validation

Testing & Evaluation Plan

1

Setup

Assemble system with known amount of food waste (e.g., vegetable waste + dry leaves).

2

Calibration

Verify temperature and moisture sensors (compare with reference thermometer and known wet/dry samples).

3

Controlled Tests

Run two cases — (A) without aeration (fan OFF), (B) with aeration (fan ON/auto).

4

Record Data

Log temperature and moisture for several days continuously.

5

Compare

Show how aeration and moisture affect composting conditions with graphs.

6

Demonstrate

Live display data and graphs (local and web dashboard).
